List in html

Unordered list

An unordered list is used to group a collection of related items in no specific order. By default, these items are displayed with bullet points

  • coffee
  • tea
  • milk

Ordered list

In HTML, an ordered list is used to display a collection of items in a specific, sequential order

  1. coffee
  2. tea
  3. milk

Description list

description list is used to represent a list of terms and their corresponding descriptions.
